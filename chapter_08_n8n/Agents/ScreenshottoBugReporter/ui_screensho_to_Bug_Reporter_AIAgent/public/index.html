How it works

  1. Upload. Your screenshot, notes and logs go to the n8n workflow. Secrets are removed and long logs are trimmed.
  2. AI analysis. A vision model (Groq Qwen, with Gemini as the fallback) reads the screen and fills in a fixed bug-report template.
  3. Jira. A Bug is created in KAN with the severity, labels and steps, and the screenshot is attached.
  4. Result. You get the issue key and a link here.
